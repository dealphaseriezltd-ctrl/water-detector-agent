# Water Detector Companion™

Field companion for PQWT / ADMT "water detector" surveys — by **Dr. Uche Aluge Daniel** (*The Borehole Doctor* 🩺).

Log profile points exactly as the device shows them, watch the profile draw live, and let the on-device AI give a **second opinion**: it stress-tests the device's claims against your terrain, nearby borehole records, and flagging behaviour — then verdicts each line as promising, shaky, or weak.

- Works fully offline — no internet needed in the field
- PQWT & ADMT model presets, configurable frequency channels
- Nearby-borehole cross-checks, site photos, voice notes
- CSV + Word-ready report export, JSON backup/restore

🌍 Live app: https://dealphaseriezltd-ctrl.github.io/water-detector-agent/
